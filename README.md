# skinock

Nock in SKI, with its jets. A Lean development joining
[lean-nock](https://github.com/sigilante/lean-nock) (Nock 4K, the three-valued jet contract,
co-derivation) to [lean-ski](https://github.com/sigilante/lean-ski) (SKI, the heap machine,
licensed jets, the circuit): a translation of Nock formulas to SKI terms that preserves
value, crash and divergence and carries jet obligations across, and a Nock program proved in
zero knowledge by the SKI circuit with no Nock circuit written.

See `PLAN.md`. Nothing is built yet.
